01 · GitHub Token

Unahitaji "Personal Access Token" ya GitHub (mara moja tu, itahifadhiwa kwenye simu yako). Nenda github.com/settings/tokens → "Generate new token (fine-grained)" → chagua repo yako pekee → ruhusa "Contents: Read and write" → tengeneza → bandika hapa chini.
Inahifadhiwa tu kwenye browser ya simu yako (localStorage) — haitumwi popote pengine isipokuwa GitHub.
